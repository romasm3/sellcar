Skelbimo kainos blokas — variantai

Kairėje viršuje — kaip yra dabar. Visos spalvos iš projekto tokenų.

Pirma — tai ne dizaino, o CSS klaida.
Kaina turi klasę text-primary, o stiliuose yra dvi konfliktuojančios taisyklės:
.text-primary { color: var(--accent-rgb) } → #374151 (teisinga)
.text-primary { color: var(--accent-grad-from) !important } → #9CA3AF (laimi dėl !important)
--accent-grad-from yra gradiento šviesiausias taškas, skirtas fonams — ne tekstui. Todėl svarbiausias puslapio skaičius nupieštas ta pačia spalva kaip neaktyvūs elementai (--text-disabled = #9CA3AF). Klasė naudojama 7 vietose šiame puslapyje.
